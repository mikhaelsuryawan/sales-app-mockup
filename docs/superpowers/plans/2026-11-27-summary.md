# Halaman Summary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganti tab Target dengan halaman Summary (filter Hari ini | Bulan ini) dan seragamkan tab bawah semua role di mockup mobile.

**Architecture:** Satu fungsi data `sumItems(per)` mengembalikan daftar item seragam per role; satu layar `SCR.summary` merender kartu utama, Yang perlu dikerjakan, Rincian, dan Pencapaian kamu dari daftar itu. Tab kedua ditentukan `navAkt()`.

**Tech Stack:** HTML/CSS/JS tanpa build, satu file `mobile/index.html`.

**Spec:** `docs/superpowers/specs/2026-11-27-summary-design.md`

## Global Constraints

- Tab bawah: Beranda, Aktivitas Saya / Aktivitas Toko, Absen, Summary, Akun. SPV dan Arco: tab kedua tetap Tim.
- Semua wording menu "Target" menjadi "Summary". Kode `SCR.target` tetap ada, tidak bisa dibuka dari menu.
- Filter Summary: Hari ini | Bulan ini, default Hari ini, disimpan di `S.sumPer` ('d' atau 'm').
- Gaya mobile: gradasi biru (#21CFF7, #0A92F2, #3466FF), aksen tan #EFA477, glass, Plus Jakarta Sans.
- Setiap baris dan tile mengarah ke sesuatu. Data fiktif saja.
- Selesai: tanpa error konsol, tanpa overflow horizontal di lebar 375, 768, 1440.

## Review Focus

- Role tanpa data di satu periode (mis. SPV Hari ini, total 0): kartu utama tidak membagi nol, tampil "Belum ada pekerjaan".
- Semua item selesai: Yang perlu dikerjakan diganti pesan tuntas, bukan daftar kosong.
- Membuka Aktivitas Saya sebagai tab (tumpukan 1 layar): tombol kembali tidak tampil.
- Ketuk baris sebelum absen masuk: memakai `act()` supaya kunci absen tetap berlaku.
- Teks panjang (nama toko, rupiah) di lebar 375: tidak memaksa overflow.
